# IntelDesign website
Static site (HTML/CSS/JS). Upload all files to a GitHub repository and enable
Settings -> Pages -> Deploy from branch (main, / root).

1. Add images/portrait.jpg (Antonios' photo).
2. TEAM: open js/team.js, copy the template block, fill in the details. Photos go
   in images/team/, CV files in cv/. Empty fields are simply not shown.
3. Background shade: the 4 dots next to EN/EL switch between darkest (default) and lightest; the choice is remembered.
4. Contact form uses https://formsubmit.co. On the FIRST submission after publishing,
   FormSubmit emails asd.inteldesign@gmail.com an activation link - click it once.
